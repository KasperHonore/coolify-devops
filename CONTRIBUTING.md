# Contributing

Problems and suggestions go in the
[issue tracker](https://github.com/KasperHonore/coolify-devops/issues). A report is
most useful with the skill name, what you typed, what the skill did, and what you
expected, with any secret or instance identifier removed.

Pull requests are welcome for the skills and their templates. Read `AGENTS.md` first:
it is the contributor guide, written for agents and people alike. Before opening a
PR, run `npm run check`; CI runs the same. Nothing in a PR may name a real server,
domain, or resource.

This repository is published from the author's private deployment repo, so a merged
PR reaches `main` through that path rather than directly. The history here is
rewritten on each publish; releases are tagged by commit and are the stable references.
